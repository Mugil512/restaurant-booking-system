# 🍽️ Restaurant Booking System

A full-stack web application to view restaurants and book tables online.

## 🚀 Features
- View restaurant list with images
- View restaurant details
- Book a table
- View bookings
- Cancel booking

## 🛠️ Tech Stack
- Backend: Spring Boot
- Database: MySQL
- Frontend: HTML, CSS, JavaScript
- Build Tool: Maven

  ## ▶️ How to Run
1. Start MySQL
2. Create database:
   CREATE DATABASE restaurant_db;
3. Update application.properties
4. Run:
   mvn spring-boot:run
5. Open:
   http://localhost:8081
